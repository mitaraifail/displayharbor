DisplayHarbor
=============

English
-------
1. Verify the downloaded DMG with the matching `.sha256` file from GitHub Releases.
2. Drag `DisplayHarbor.app` to the `Applications` folder.
3. Launch DisplayHarbor from Applications.
4. Grant DisplayHarbor access in System Settings > Privacy & Security > Accessibility.

简体中文
--------
1. 使用 GitHub Release 中对应的 `.sha256` 文件校验下载的 DMG。
2. 将 `DisplayHarbor.app` 拖到“应用程序”文件夹。
3. 从“应用程序”启动 DisplayHarbor。
4. 请到“系统设置 → 隐私与安全性 → 辅助功能”授予 DisplayHarbor 权限。
